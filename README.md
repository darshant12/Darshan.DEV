# Personal Portfolio Website

A complete, responsive personal portfolio website built to showcase my skills, projects, and professional background.

## 🚀 Live Demo
https://personal-portfolio-aqpm.vercel.app/
## 🎯 Objective
The primary objective of this project was to combine HTML structure, CSS styling, responsive design principles, and basic JavaScript into a practical, professional portfolio that highlights my capabilities as an AI-ML Undergraduate and Full-Stack Developer.

## 🛠️ Approach & Methodology
1. **Structural Design (HTML5):** 
   - Planned and implemented a semantic page structure with distinct sections: Home, About, Skills, Projects, and Contact.
   - Ensured accessibility and clean code organization.
2. **Styling & Aesthetics (CSS3):**
   - Adopted a modern, dark-themed aesthetic with vibrant neon accents and "Glassmorphism" UI elements for a premium feel.
   - Utilized CSS Flexbox and CSS Grid to create a fluid, responsive layout that adapts seamlessly across mobile, tablet, and desktop devices.
   - Implemented consistent spacing, typography, and hover micro-animations to enhance user engagement.
3. **Interactivity (JavaScript):**
   - Added smooth scrolling for navigation links.
   - Integrated the `IntersectionObserver` API to trigger scroll-based reveal animations as elements enter the viewport.
   - Implemented client-side form validation for the contact section to ensure data integrity before submission.
4. **Asset Management:**
   - Generated custom, high-quality cover images tailored to the specific theme of each project (e.g., AI Voice Analysis, Agritech, Civic Tech, Secure Voting).

## 🏆 Outcome & Deliverables
- **Fully Responsive Design:** The portfolio looks great and functions perfectly on all screen sizes.
- **Project Showcase:** Successfully integrated 4 major projects (VoiceIQ, Online Voting Platform, Smart Civic Connect, Smart Krishi) with descriptive cards, tech stack tags, and links to live demos and GitHub repositories.
- **Working Navigation & Contact:** A sticky navigation menu for easy browsing and a validated contact form for inquiries.
- **Professional Resume Integration:** Direct download link configured for my most up-to-date PDF resume.

## 💻 Tech Stack
- **HTML5**
- **CSS3** (Flexbox, Grid, Animations)
- **JavaScript** (Vanilla JS, DOM Manipulation)
